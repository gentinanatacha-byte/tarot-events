COMMENT FAIRE SUR GITHUB (depuis l'ordinateur)
──────────────────────────────────────────────
Pour chaque fichier, un par un :
  1. Sur github.com, ouvre ton dépôt tarot-events.ch
  2. Clique sur le DOSSIER de destination (ex. _includes)
  3. Bouton « Add file » → « Upload files »
  4. Glisse le fichier
  5. En bas, « Commit changes »

GitHub remplace automatiquement un fichier qui porte le même nom dans
le même dossier. Tu peux aussi déposer plusieurs fichiers d'un même
dossier en une seule fois.

Compte 2 à 3 minutes après le dernier dépôt pour que le site se
reconstruise, puis recharge la page en vidant le cache (Ctrl+Maj+R, ou
Cmd+Maj+R sur Mac).
